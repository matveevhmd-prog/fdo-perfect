## 0. Що відомо про вузли (Факт, з `workflows/DEMO_Archi_Agent_Core.json`, версія `8a9fe9e5`)

- Усі чотири вузли — `n8n-nodes-base.postgres` v2.6: `WR: Inbox Add`, `Import: Insert Time Rows`, `Import: Insert Money Rows`, `Meeting: Insert Rows`. Запит починається з `=`, значення вставлено як `'{{ … .replace(/'/g, "''") }}'` (екранується лише апостроф).
- Взірець параметризації вже є: `K: Save Mode`, `KP Log: Insert Row`, `Doc Intake: Write Link URL`. Запит — без `=` на початку, з `$1…$n`; значення — `options.queryReplacement = "={{ [ … ] }}"`.
- `WR: Inbox Add` повторює `payload` двічі (INSERT і `WHERE length(trim(...)) > 0`) — з параметрами це один `$3`. `session_id` = `String(chat.id)`.
- `Import: Insert Time/Money Rows` і `Meeting: Insert Rows` виконуються по одному разу на кожен рядок; нижче цих вузлів вихідних з'єднань немає.
- `$json.Виконавець.replace(…)`, `$json.Контрагент.replace(…)`, `$json.Учасники.replace(…)` кидають помилку, якщо поле порожнє. З параметрами (`String(x ?? '')` + `NULLIF`) порожнє поле стане `NULL`. Це **зміна поведінки** — назвати власнику й записати в RELEASE_PLAN §116.
- Дати розбираються регулярками в SQL. Для параметрів потрібне явне `::text` (`LEFT($n::text, 10)::date`, `TO_DATE($n::text, 'DD.MM.YYYY')`), інакше Postgres не виведе тип; числа — `NULLIF(REPLACE(REPLACE($n::text,' ',''),',','.'),'')::numeric`.
