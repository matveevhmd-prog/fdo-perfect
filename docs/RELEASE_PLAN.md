## 4b. Довірчий тест Кроку 8 — повний реальний сценарій (13.09.2026)

Після SQL-перевірки вище власник (Андрій) справедливо вказав, що тестове
повідомлення, яке прийшло йому в Telegram ("Тестовий фінальний звіт", 2
рядки), не схоже на реальний продукт. Причина: для попереднього тесту я
підмінив відповідь LLM-агента власним заглушковим текстом — реальний
шаблон звіту (5 секцій за `WR: Build WR Prompt`) жодного разу не був
показаний. Провів повторний тест — цього разу без жодної підміни LLM,
через справжню розмову з ботом: `проєкт DEMO-01` → повна диктовка
чек-листа вільним текстом → `фінал`.

**Знайдено і виправлено реальний production-баг**, не пов'язаний з Кроком
8/9: нода `WR: Determine Route` рахувала `is_wr_flow` через JS-ланцюжок
`||`, останній операнд якого — сирий рядок `text`, а не boolean
(`false || false || false || "якийсь текст"` в JS повертає сам рядок, не
`true`). Через це `IF`-нода `WR: Is WR Flow?` (сувора boolean-перевірка)
падала з помилкою для БУДЬ-ЯКОГО вільного тексту-диктовки, що не починався
зі слова "додати" і не збігався з фіксованою командою. Це означає: **до
цього фіксу реальний ПМ, що просто пише вільним текстом чек-лист, ламав
бота.** Виправлено обгортанням у `Boolean(...)`, опубліковано, перевірено
повторним прогоном — спрацювало.

Після фіксу — повний робочий цикл: справжній Claude-агент згенерував
коректний 5-секційний чернетковий звіт (систему стадій, Залишок_прогноз
по кожній стадії окремо, ймовірності Акту/документації — усе за
шаблоном), гейт `FINAL_REPORT` спершу примусово знизив до `DRAFT` (бо
команди "фінал" ще не було), потім після "фінал" — реальний
`FINAL_REPORT`, з мандатним блоком "Статус плану минулого тижня".

Крок 8 порахував з **реальних продиктованих чисел** (не синтетики):

| Поле | Значення |
|---|---|
| etc_forecast_total_hours | 400 (0+40+140+220 по стадіях) |
| actual_hours | 103 (з time_log) |
| profit_forecast | 263 324 |
| profitability_forecast_pct | **31.6%** |

Дані попереднього синтетичного тесту (та ж неділя) коректно перезаписані
через `ON CONFLICT DO UPDATE` — прибирати вручну не знадобилось.
