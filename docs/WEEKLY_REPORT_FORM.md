## 1. Шаблон звіту, що вже є в коді (WR-агент, Telegram)

Жорсткий шаблон у промпті. Порядок і нумерація:

```
Рентабельність_Total: план X% / прогноз Y%
ETC_Total: план …г / факт …г / прогноз …г (сума ETC_прогноз по 4 стадіях)

1. Готовність (%)_Total: прогноз N
 1.1 Стадія МБР: 🟢 або "прогноз Y%"
  1.1.1 ETC_Стадія МБР: план / факт / прогноз        (пропускається, якщо 🟢)
  1.1.2 Дедлайн МБР: план ДАТА / прогноз ДАТА        (пропускається, якщо 🟢)
 1.2 ЕП …   1.3 П …   1.4 Р …   (те саме)
2. Акти
 2.1–2.4 Стадії МБР/ЕП/П/Р: "✅ (підписаний)" або "ДАТА / N/10"   (АВТО з Money_Log)
 2.5 Ймовірність видачі документації: N/10
3. КОМЕНТАРІ ПМ
4. ПРОБЛЕМИ   (⛔ Блокер першим пунктом, якщо є)
5. ДОПОМОГА
6. ПЛАН НА ТИЖДЕНЬ   (невиконане з минулого тижня — з міткою 🔴)
```

Без грошових сум. Пороги/кольори — з `archi_thresholds`. Дати в тексті ДД.ММ.РРРР.

Автоматично (ПМ не питається): ETC_план, ETC_факт, Дедлайн_план, статус Актів,
act_probability, перевірка ⚖️ розбіжності готовності.
Збирається від ПМ (чек-лист у промпті): готовність по 4 стадіях → ETC_прогноз по
стадіях → дедлайн (без змін / нова дата) → ймовірність документації → актуальність
Актів → блокер; + статус пунктів минулого плану.
